# 复旦大学期中期末往年卷（按科目、老师整理）

把网上公开分享的复旦期中、期末卷集中到一起，按 **科目 → 老师** 两层整理，方便按自己老师找卷子复习。

> **版权说明**：试卷的版权归出题教师、复旦大学和原整理者所有。本仓库只做收集和分类，仅供学习交流，**禁止商用、禁止售卖**。
> 如果你是版权所有者，或者认为某份文件不应公开，请提 Issue，会尽快删除。

## 目录结构

```
科目/
  拼音缩写_老师全名/    例如 fh_冯辉
  统考/                全校统一命题（高数、线代期末，大物 B 期末，思政，军理，生导，基物实验，Python 等）
  佚名/                找不到老师的
```

- 科目名是“大类-课名”，例如 `数学-线性代数`、`物理-大学物理B下`。
- 只收期中、期末卷（含期末回忆版、答案、讲评）。小测、模拟卷、题库、课件、笔记都没有收。
- 数学分析 B 的“阶段性考试”保留了（谢锡麟班用它代替期中）。
- 加密 PDF 的密码写在文件名里。
- `*_考题回忆(Notion题库).md` 是学生考后回忆的题目文字。
