## 3. cache

给定了 cache 中存放的内容
1) 计算 CO, CI, CT 的位数；
2) 手工模拟两个 cache，其中一个命中另一个因为有效位为 0 而不命中
3) 定义了二维数组 `A[N][N]` 和 `B[N][N]`，数组中放的 `sizeof(double) = 8`，cache 总大小 64B，二路组相联，分为 2 组，考虑下列程序片段：

```c
for (int i = 0; i < N; ++i)
    for (int j = 0; j < N; ++j)
        x += a[i][j] + b[j][i];
```

计算 `N = 2` 和 `N = 4` 时的命中率。

Nova 注：第二问类似于中文版 CSAPP 课本 P429 **综合：运行中的直接映射高速缓存**
